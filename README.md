# American Sign Language Detection
A computer vision model that detects hand sign language and identify the letter.
## About
Object detection is the prime focus in medical imaging, security surveillance and auto-pilot modes in cars. One such domain where we can apply object detection is sign language detection. Recently, sign language has been identified as a prominent communication medium in society. Sign language is used extensively in live interviews, shows, and public gatherings. One of the crucial problems with sign language is to identify hand gestures and learn the language itself. Objection detection algorithms such as Yolo can be employed in these scenarios as these algorithms can detect any object and label it correctly.
